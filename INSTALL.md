# Nebula for GitHub — 直接安装 / Quick install

版本 / Version: 1.2.3

## 中文

1. 安装浏览器扩展 Stylus。
2. 打开固定安装链接，点击“安装样式”或“更新”：
   https://raw.githubusercontent.com/saladinxp/github-nebula-theme/main/dist/nebula-github.user.css
3. 打开 Stylus 管理页，找到 Nebula，点击旁边的齿轮。
4. 在“配色模式 / Color mode”中选择“浅色”“深色”或“跟随 GitHub”，保存。

也可以把本压缩包中的 `nebula-github.user.css` 拖到 Stylus 管理页安装。建议使用上面的固定链接，以便后续检查更新。

已有1.2.2的用户需更新到1.2.3后才有独立配色选项。通过粘贴普通CSS创建的旧样式没有这些选项；安装UserCSS后，只保留一份启用的Nebula。

本包已经构建好，直接安装即可。`fonts/` 中的三个TTF字体是可选的；不安装也能使用主题。中文使用系统字体。

## English

1. Install the Stylus browser extension.
2. Open the permanent installation URL above and click Install style / Update.
3. In Stylus Manage, find Nebula and click its gear / Configure icon.
4. Choose Light, Dark, or Follow GitHub under Color mode, then save.

Alternatively, drag the bundled `nebula-github.user.css` into the Stylus Manage page. The permanent URL is recommended for future update checks. Users on 1.2.2 need to update to 1.2.3 to see Color mode. Styles made by pasting plain CSS have no configuration options; keep only one enabled Nebula copy after installing the UserCSS.

The files are ready to install. The three TTF files in `fonts/` are optional; system fonts work without them.

Source and full documentation: https://github.com/saladinxp/github-nebula-theme
