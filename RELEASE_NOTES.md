Browser theme for **github.com**, installed with Stylus. / 用于 **github.com** 的浏览器主题，通过 Stylus 安装。

- **[Install / 安装 UserCSS](https://raw.githubusercontent.com/saladinxp/github-nebula-theme/main/dist/nebula-github.user.css)**
- **[nebula-github-1.2.1.zip](https://github.com/saladinxp/github-nebula-theme/releases/download/v1.2.1/nebula-github-1.2.1.zip)** — complete ZIP: CSS, optional fonts, source, offline previews, and licenses. / 完整安装包：CSS、可选字体、源码、离线预览和许可证。
- [English install and update guide](https://github.com/saladinxp/github-nebula-theme/blob/v1.2.1/README.md) · [中文安装和更新说明](https://github.com/saladinxp/github-nebula-theme/blob/v1.2.1/README.zh-CN.md)
- [SHA-256 checksums](https://github.com/saladinxp/github-nebula-theme/releases/download/v1.2.1/release-SHA256SUMS.txt) — the ZIP also contains per-file `SHA256SUMS`. / ZIP 内另附逐文件校验清单。

**Color mode / 配色：** use [GitHub Settings → Appearance](https://github.com/settings/appearance). The offline preview's Light / Dark buttons are demo controls, not buttons added to the live site. / 在 GitHub 外观设置中切换；离线预览的配色按钮不会添加到实际页面。

**Updates / 更新：** install from the permanent UserCSS link, then use Stylus **Check for updates**. Keep only one enabled copy. / 从固定链接安装后，在 Stylus 管理页检查更新，只保留一份启用的主题。

See [Changelog](https://github.com/saladinxp/github-nebula-theme/blob/v1.2.1/CHANGELOG.md) for the included features.
